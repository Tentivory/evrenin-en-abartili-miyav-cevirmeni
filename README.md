# Evrenin En Abartılı Miyav Çevirmeni

## Bilimsel Özet

Bu proje, insanlığın en büyük sorunlarından birini çözmek için geliştirilmiştir: **Kedilerle iletişim kuramamak**.

Yıllar süren araştırmalar, kuantum hesaplamalar ve 47 kediyle yapılan gizli deneyler sonucunda, herhangi bir metni %100 doğrulukla kedi diline (özellikle miyav) çeviren algoritma keşfedilmiştir.

**Uyarı:** Bu yazılım ciddiye alınmalıdır. Kediler bu çeviriyi onaylamıştır. Onaylamayan kediler henüz test edilmemiştir.

## Özellikler

- Herhangi bir Türkçe (veya başka dil) metni miyava çevirir
- Rastgele miyav varyasyonları kullanır (bilimsel çeşitlilik için)
- Komut satırından çalışır, gerçekten
- Aşırı abartılı ve gereksiz
- Kedileri kızdırma riski %0.0001 (test edilmedi)

## Kurulum ve Kullanım

```bash
python3 miyav_cevirmen.py "Merhaba dünya, ben bir insanım"
```
